# Tidal Connect Support

## Overview
Tidal's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-tidal:
```
opkg install node-red
npm install node-red-contrib-tidal
```

## Usage
- Stream Tidal to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires Tidal subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
