# IoT Device Support

## Overview
Support for IoT devices (sensors, actuators, smart home).
MQTT, CoAP, HTTP protocols.

## MQTT Broker
- Install mosquitto:
```
opkg install mosquitto mosquitto-client
```
- Configure /etc/mosquitto/mosquitto.conf
- Start: /etc/init.d/mosquitto start

## MQTT Client
- mosquitto_sub -t 'sensors/#' -h localhost
- mosquitto_pub -t 'actuators/light' -m 'on'

## Home Assistant
- Run on external server
- Connect via MQTT or HTTP
- Control devices through LuCI

## Notes
- 390 MHz CPU limits MQTT clients
- Use lightweight protocols
- Consider external broker
