# TuneIn Support

## Overview
TuneIn's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-tunein:
```
opkg install node-red
npm install node-red-contrib-tunein
```

## Usage
- Stream TuneIn to router
- Control via HTTP
- Multi-room audio

## Notes
- Free tier available
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
