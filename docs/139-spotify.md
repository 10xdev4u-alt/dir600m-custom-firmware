# Spotify Connect Support

## Overview
Spotify's streaming protocol for audio.
librespot implementation.

## Software
- librespot:
```
opkg install librespot
librespot --name "DIR-600M" --backend alsa
```

## Usage
- Stream Spotify to router
- Control via Spotify app
- Multi-room audio

## Notes
- Heavy for 390 MHz CPU
- Requires Spotify Premium
- Network streaming only
- No video support
