# DAC (Digital-to-Analog Converter)

## Overview
Generate analog voltages for control/audio.
RTL8196C has no internal DAC.

## Hardware
- External DAC (MCP4725, PCM5102)
- I2C or SPI interface
- Audio amplifiers

## Software
- I2C DAC:
```
opkg install kmod-i2c-dev
i2cset -y 0 0x60 0x00 0x80
```

## Usage
- Voltage control
- Audio generation
- Signal generation
- Motor control

## Notes
- External DAC required
- I2C or SPI interface
- 3.3V output max
- Amplifier needed for audio
