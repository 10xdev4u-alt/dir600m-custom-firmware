# GPS Support

## Overview
GPS for location tracking and time sync.
Requires USB GPS receiver.

## Hardware
- USB GPS receiver (u-blox, GlobalSat)
- kmod-usb-serial for serial communication

## Software
- gpsd:
```
opkg install gpsd gpsd-clients
gpsd /dev/ttyUSB0
cgps -s
```

## Usage
- Location tracking
- Time synchronization (NTP)
- Geofencing
- Data logging

## Integration
- MQTT for Home Assistant
- HTTP API for custom scripts
- KML/GPX export

## Notes
- USB GPS required
- Antenna needed for indoor use
- 1Hz update rate typical
