# YouTube Music Support

## Overview
YouTube Music's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-youtube-music:
```
opkg install node-red
npm install node-red-contrib-youtube-music
```

## Usage
- Stream YouTube Music to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires YouTube Music subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
