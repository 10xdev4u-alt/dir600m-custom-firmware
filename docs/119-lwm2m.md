# LwM2M Protocol

## Overview
Lightweight M2M protocol for IoT device management.
CoAP-based, standardized.

## Hardware
- LwM2M sensors/actuators
- CoAP over UDP
- DTLS for security

## Software
- wakaama:
```
opkg install wakaama
```

## Objects
- Security (0)
- Server (1)
- Device (3)
- Temperature (3303)
- Humidity (3304)

## Integration
- Leshan LwM2M server
- Home Assistant via MQTT bridge
- Custom CoAP client

## Notes
- Standardized (OMA)
- DTLS mandatory for security
- Bootstrap for provisioning
