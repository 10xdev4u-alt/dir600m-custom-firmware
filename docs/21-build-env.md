# Build Environment Requirements

## Host
- Linux (Ubuntu 12.04/14.04 recommended)
- 4GB+ RAM
- 40GB+ disk
- gcc 4.x, make, python

## Packages
build-essential libncurses5-dev zlib1g-dev gawk git subversion python unzip wget

## Toolchain (auto-built)
- gcc 4.5-linaro
- binutils 2.21.1
- uClibc

## Build time
- Toolchain: ~1-2 hours
- Kernel + packages: ~30 min
- Total: ~2-3 hours
