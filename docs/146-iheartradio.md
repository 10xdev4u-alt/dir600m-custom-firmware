# iHeartRadio Support

## Overview
iHeartRadio's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-iheartradio:
```
opkg install node-red
npm install node-red-contrib-iheartradio
```

## Usage
- Stream iHeartRadio to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires iHeartRadio account
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
