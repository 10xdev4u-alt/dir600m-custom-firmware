# AFP (Apple Filing Protocol)

## Overview
Apple's file sharing protocol.
Netatalk implementation.

## Server
- /etc/netatalk/afpd.conf:
```
- -tcp -noddp -uamlist uams_dhx.so,uams_guest.so
```
- /etc/netatalk/AppleVolumes.default:
```
/mnt/usb "USB Share"
```
- Start: /etc/init.d/netatalk start

## Client
- Finder -> Go -> Connect to Server
- afp://192.168.0.1

## Usage
- Mac file sharing
- Time Machine backup

## Notes
- Heavy for 390 MHz CPU
- SMB preferred for modern Macs
- AFP deprecated by Apple
