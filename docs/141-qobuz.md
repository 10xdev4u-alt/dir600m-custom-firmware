# Qobuz Support

## Overview
Qobuz's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-qobuz:
```
opkg install node-red
npm install node-red-contrib-qobuz
```

## Usage
- Stream Qobuz to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires Qobuz subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
