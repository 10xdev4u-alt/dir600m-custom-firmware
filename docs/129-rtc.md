# RTC (Real-Time Clock)

## Overview
Battery-backed clock for accurate time.
Useful for scheduled tasks.

## Hardware
- DS3231 (I2C, accurate)
- DS1307 (I2C, less accurate)
- Battery: CR2032

## Software
- hwclock:
```
opkg install kmod-i2c-dev kmod-rtc-ds1307
hwclock -w
hwclock -s
```

## Usage
- Accurate timestamps
- Scheduled tasks (cron)
- Data logging
- Time-based automation

## Notes
- Battery backup required
- I2C interface
- 3.3V logic
- Check kernel module for chip
