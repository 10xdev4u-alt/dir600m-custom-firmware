# Chromecast Support

## Overview
Google's casting protocol for media streaming.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-cast:
```
opkg install node-red
npm install node-red-contrib-cast
```

## Usage
- Cast video/audio to Chromecast
- Control via HTTP
- Multi-room audio

## Notes
- Requires Chromecast device
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
