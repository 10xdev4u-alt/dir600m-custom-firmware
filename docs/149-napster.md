# Napster Support

## Overview
Napster's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-napster:
```
opkg install node-red
npm install node-red-contrib-napster
```

## Usage
- Stream Napster to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires Napster subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
