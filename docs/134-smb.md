# SMB/CIFS Support

## Overview
Windows file sharing protocol.
Samba implementation.

## Server
- /etc/samba/smb.conf:
```
[global]
    workgroup = WORKGROUP
    security = user

[share]
    path = /mnt/usb
    read only = no
    guest ok = yes
```
- Start: /etc/init.d/samba start

## Client
- mount -t cifs //192.168.0.1/share /mnt/smb
- smbclient //192.168.0.1/share

## Usage
- Windows file sharing
- Mac file sharing
- Printer sharing

## Notes
- Heavy for 390 MHz CPU
- Use lightweight alternatives
- SMB1 insecure, use SMB2/3
