# Amazon Music Support

## Overview
Amazon's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-amazon-music:
```
opkg install node-red
npm install node-red-contrib-amazon-music
```

## Usage
- Stream Amazon Music to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires Amazon Music subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
