# DLNA/UPnP Media Server

## Overview
Stream media to TVs, game consoles, and other devices.
UPnP/DLNA protocol.

## Software
- minidlna:
```
opkg install minidlna
```
- /etc/config/minidlna:
```
option media_dir '/mnt/usb'
option friendly_name 'DIR-600M'
```

## Usage
- Stream video/music/photos
- TV, console, phone support
- Automatic discovery

## Notes
- Heavy for 390 MHz CPU
- Use low-res media
- External storage recommended
- Limited format support
