# Kernel Modules (kmod)

## Network
- kmod-tun: TUN/TAP tunnel
- kmod-ipt-core: iptables core
- kmod-ipt-nat: NAT
- kmod-ipt-conntrack: connection tracking

## Filesystems
- kmod-fs-ext4: ext4 support
- kmod-fs-vfat: FAT support
- kmod-fs-squashfs: SquashFS
- kmod-fs-jffs2: JFFS2

## USB
- kmod-usb-ohci: USB OHCI
- kmod-usb-uhci: USB UHCI
- kmod-usb2: USB 2.0
- kmod-usb-serial: USB serial
- kmod-usb-storage: USB storage

## Wireless
- kmod-cfg80211: wireless config
- kmod-mac80211: wireless stack
- kmod-rtl8192cd: Realtek wireless
