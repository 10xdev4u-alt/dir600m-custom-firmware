# CAN Bus Support

## Overview
Controller Area Network for automotive/industrial.
Requires USB-CAN adapter.

## Hardware
- USB-CAN adapter (SocketCAN)
- CAN transceiver (MCP2551)
- 120Ω termination resistors

## Software
- can-utils:
```
opkg install can-utils
ip link set can0 up type can bitrate 125000
candump can0
```

## Usage
- cansend can0 123#DEADBEEF
- candump can0
- cansniffer can0

## Integration
- Home Assistant via MQTT
- HTTP API for custom scripts
- Automotive diagnostics

## Notes
- USB-CAN adapter required
- Bitrate must match bus
- Termination resistors required
