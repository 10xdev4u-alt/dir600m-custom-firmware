# RTL8196C Variants

## RTL8196C
- Base variant
- 2x Ethernet, USB, Wireless
- 390 MHz

## RTL8196D
- Higher clock (500 MHz)
- More peripherals
- PCIe support

## RTL8196E
- Lower power
- Integrated PHY
- SDIO interface

## RTL8198
- Dual core (2x Lexra)
- Gigabit Ethernet
- PCIe, USB 3.0
- Higher end

## Compatibility
- Same toolchain (mips-linux-uclibc)
- Same kernel (2.6.30/2.6.32)
- Different DTS/device tree
- Different wireless calibration
