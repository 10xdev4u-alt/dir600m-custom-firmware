# RTL8196C Datasheet Summary

## CPU Core
- Lexra 4181 (modified MIPS-I R3000)
- 390 MHz clock speed
- 16-bit data path (partially)
- No FPU (software floating point)
- DSP extensions available

## Memory
- 32 MB SDRAM (max)
- 4 MB SPI flash (typical)
- SD/SDIO interface

## Peripherals
- 2x Ethernet MAC (10/100)
- 1x Ethernet PHY
- SPI, I2C, UART, GPIO
- USB 2.0 host (OHCI/uhCI)
- PCI/PCIe (RTL8196E+)
- Wireless MAC (802.11n)

## Power
- 3.3V core
- ~2-3W typical
- Sleep modes available

## Package
- QFP or BGA (depending on variant)
