# NFS Support

## Overview
Network File System for sharing files.
Linux-native, efficient.

## Server
- /etc/exports:
```
/mnt/usb 192.168.0.0/24(rw,sync,no_subtree_check)
```
- Start: /etc/init.d/nfsd start

## Client
- mount -t nfs 192.168.0.1:/mnt/usb /mnt/nfs
- /etc/fstab:
```
192.168.0.1:/mnt/usb /mnt/nfs nfs defaults 0 0
```

## Usage
- File sharing between Linux machines
- Centralized storage
- Backup target

## Notes
- NFSv4 recommended
- Firewall rules needed
- Performance limited by 100 Mbps Ethernet
