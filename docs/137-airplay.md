# AirPlay Support

## Overview
Apple's streaming protocol for audio/video.
Shairport implementation.

## Software
- shairport-sync:
```
opkg install shairport-sync
/etc/init.d/shairport-sync start
```

## Usage
- Stream audio from iOS/macOS
- AirPlay 2 support (limited)
- Multi-room audio (with other devices)

## Notes
- Heavy for 390 MHz CPU
- Use USB audio output
- Network streaming only
- No video support
