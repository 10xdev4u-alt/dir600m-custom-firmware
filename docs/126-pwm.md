# PWM (Pulse Width Modulation)

## Overview
PWM for controlling brightness, speed, motor position.
Available on GPIO pins.

## Hardware
- LEDs (brightness control)
- Motors (speed control)
- Servos (position control)

## Software
- sysfs:
```
echo 1000 > /sys/class/pwm/pwmchip0/pwm0/period
echo 500 > /sys/class/pwm/pwmchip0/pwm0/duty_cycle
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable
```

## Notes
- PWM frequency limited by CPU
- Hardware PWM preferred
- Software PWM via GPIO
- Check SoC for PWM channels
