# I2C Bus Support

## Overview
Inter-Integrated Circuit for connecting sensors/actuators.
2-wire serial bus.

## Hardware
- Sensors: BME280, BMP180, MPU6050
- ADCs: ADS1115
- RTC: DS3231
- EEPROM: 24C256

## Software
- i2c-tools:
```
opkg install i2c-tools
i2cdetect -y 0
i2cget -y 0 0x76 0x40
i2cset -y 0 0x76 0x40 0x01
```

## Kernel
- kmod-i2c-core
- kmod-i2c-gpio (bit-bang)
- kmod-i2c-dev

## Notes
- 3.3V logic
- Pull-up resistors (4.7k) required
- Max speed: 400 kHz (fast mode)
