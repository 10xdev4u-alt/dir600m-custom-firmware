# SoundCloud Support

## Overview
SoundCloud's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-soundcloud:
```
opkg install node-red
npm install node-red-contrib-soundcloud
```

## Usage
- Stream SoundCloud to router
- Control via HTTP
- Multi-room audio

## Notes
- Free tier available
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
