# Pandora Support

## Overview
Pandora's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-pandora:
```
opkg install node-red
npm install node-red-contrib-pandora
```

## Usage
- Stream Pandora to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires Pandora subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
