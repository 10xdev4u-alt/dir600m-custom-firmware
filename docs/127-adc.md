# ADC (Analog-to-Digital Converter)

## Overview
Read analog sensors (temperature, light, voltage).
RTL8196C has internal ADC.

## Hardware
- Internal ADC (RTL8196C)
- External ADC (MCP3008, ADS1115)
- Sensors: thermistors, LDRs, voltage dividers

## Software
- Internal:
```
cat /sys/bus/iio/devices/iio:device0/in_voltage0_raw
```
- External (SPI):
```
opkg install kmod-spi-dev
```

## Notes
- 3.3V reference voltage
- 10-bit resolution (internal)
- Level shifters for >3.3V
- Filtering for noise
