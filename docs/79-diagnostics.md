# System Diagnostics

## Network
- ping: test connectivity
- traceroute: trace route
- netstat: network connections
- ifconfig: interface status
- iwconfig: wireless info

## System
- top: process monitor
- free: memory usage
- df: disk usage
- dmesg: kernel messages
- lsmod: loaded modules

## Wireless
- iw dev: wireless devices
- iw scan: scan networks
- iw link: connection status
- cat /proc/net/wireless: signal strength

## Logs
- logread: system log
- logread -f: follow logs
- logread | grep error: errors only
