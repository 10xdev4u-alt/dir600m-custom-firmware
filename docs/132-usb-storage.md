# USB Storage Support

## Overview
USB flash drives and HDDs for expanded storage.
USB 2.0 host controller.

## Hardware
- USB flash drive
- USB HDD (powered hub recommended)
- USB SSD (low power)

## Software
- kmod-usb-storage
- kmod-fs-ext4 (or vfat, ntfs)
- block-mount

## Usage
- Storage expansion
- Data logging
- Media server
- Firmware backup

## Notes
- Power may be limited
- Use powered hub for HDDs
- FAT32 for compatibility
- ext4 for Linux
