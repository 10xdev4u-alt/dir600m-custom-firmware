# SPI Bus Support

## Overview
Serial Peripheral Interface for high-speed devices.
4-wire synchronous bus.

## Hardware
- Sensors: MCP3008 (ADC), MAX6675 (thermocouple)
- Displays: ST7735 (TFT)
- SD cards: SPI SD reader
- LoRa: SX1276

## Software
- spidev:
```
opkg install kmod-spi-dev
ls /dev/spidev*
```

## Usage
- spidev_test /dev/spidev0.0
- Custom C programs
- Python spidev

## Notes
- 3.3V logic
- CS, SCK, MOSI, MISO
- Max speed: 50 MHz (but CPU limited)
