# Deezer Support

## Overview
Deezer's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-deezer:
```
opkg install node-red
npm install node-red-contrib-deezer
```

## Usage
- Stream Deezer to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires Deezer subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
