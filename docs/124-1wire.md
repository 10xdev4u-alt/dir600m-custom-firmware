# 1-Wire Bus Support

## Overview
Dallas 1-Wire protocol for sensors and IDs.
Single data line + ground.

## Hardware
- Temperature: DS18B20
- ID: DS2401 (iButton)
- Counters: DS2423

## Software
- w1-gpio:
```
opkg install kmod-w1-gpio kmod-w1-therm
cat /sys/bus/w1/devices/28-*/w1_slave
```

## Usage
- Temperature monitoring
- Device identification
- Data logging

## Notes
- 4.7k pull-up resistor required
- Parasite power or external
- Multiple devices on one bus
