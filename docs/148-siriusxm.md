# SiriusXM Support

## Overview
SiriusXM's streaming protocol for audio.
Not natively supported, requires bridging.

## Software
- node-red + node-red-contrib-siriusxm:
```
opkg install node-red
npm install node-red-contrib-siriusxm
```

## Usage
- Stream SiriusXM to router
- Control via HTTP
- Multi-room audio

## Notes
- Requires SiriusXM subscription
- Heavy for 390 MHz CPU
- Network streaming only
- Bridging required
